# 语音语言与未选中文档确认（2026-09-05）

之前两条 ASR 链路没有指定语言，短句、含糊发音或环境声音可能导致自动语言识别选错。没有原始录音，无法确认用户遇到的那一次具体是哪种原因。

现在页面提供 English（默认）、中文、Auto-detect / mixed languages。Mic 和 Live Call 使用同一选择。切换语言后需要重新开始 Live Call。指定语言是识别提示，不保证彻底消除转写错误；选英语时不适合持续中英混说。

未选中文档确认流程：

1. 用户问文档问题，服务器先用文件名或已有本地向量索引判断是否有更相关的未选中文档。
2. 如果发现候选，显示并读出“某文件可能有相关信息，要选择并继续回答吗？”。不会把候选正文提供给回答模型。
3. 用户回复 yes / yes please / 好的 / 可以，服务器才自动勾选，恢复原问题并检索正文。
4. 用户拒绝则不勾选。新问题取消旧提议；提议十分钟过期；不同对话不能互相确认。

当前一次提议一个文件，语义阈值是经验值，可能漏掉相关文件，因此仍保留手动勾选。系统不把相似度当成“文档一定包含答案”的证据。

可复现检查：先启动 14_run_backend.py，再运行 `.venv/Scripts/python.exe scripts/verify_document_access.py`。测试调用真实 API、有少量模型费用，报告写入独立时间戳目录，并清理自己创建的临时对话。

本次真实接口验证：未选 Treasury → 请求确认 → yes please → 自动选中 → 正确回答 £23.6bn / PDF 第22页。英文 Mic 样本精确转写，ASR 1.158秒。Realtime 验证涵盖后端确认接口与前端事件模拟，没有冒充真实麦克风端到端测试。
